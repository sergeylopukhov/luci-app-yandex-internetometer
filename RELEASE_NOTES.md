# История версий

## Версия 2.1.0

- Изменён порядок замера: входящая скорость, исходящая скорость, затем задержка. Между этапами добавлена пауза 0,5 секунды. Шкала спидометра на каждом этапе скорости начинается с нуля.
- Добавлена пиковая скорость в «Подробностях», истории и экспорте CSV. В таблице она указана под средней скоростью; для прежних записей доступно только среднее значение.
- Скорость и задержка отображаются с двумя знаками после точки. Если выключить «Дробные значения» в настройках, показатели станут целыми. Минимальная задержка в этом режиме — 1 мс.
- Итоги замера фиксируются сразу. Плавная анимация применяется только к текущей скорости; при открытии страницы и проверке обновлений значения больше не анимируются повторно.
- Исправлено наложение показателей скорости при четырёхзначных значениях. Рядом с кнопкой замера оставлен публичный IP без подписи.
- Число запросов для замера задержки по умолчанию уменьшено с 60 до 30. Сохранённое значение при обновлении не меняется.

## Версия 2.0.0

Переработан замер скорости: меньше нагрузка на процессор роутера, стабильнее передача данных. Исходящая скорость рассчитывается по объёму, который принял сервер Яндекса.

- Добавлен нативный движок с постоянными соединениями и небольшими буферами. Для исходящего замера больше не нужен временный файл с тестовыми данными.
- Первая секунда отводится на разгон соединений и не учитывается в результате. Неполный серверный счётчик не принимается за завершённый замер.
- Исправлены ошибки входящего замера в резервном движке на curl. Добавлены повторные подключения при обрыве связи и проверка ошибок HTTP.
- Число потоков подбирается автоматически с учётом процессора и свободной памяти. При недоступности нативного движка используется curl; в режиме HTTPS сохранена проверка TLS.
- Обновлены график истории и анимация показателей. На графике видны оба направления, средние значения и лучшие результаты.
- Исправлена плашка обновления: длинная команда прокручивается внутри поля, а кнопка копирования переносится на новую строку при нехватке места.
- APK и IPK собираются отдельно для каждой архитектуры. Установщик выбирает пакет для роутера; на ARMv4/ARMv5 используется резервный движок.

При обновлении число потоков и протокол однократно переводятся в режим «Авто». Прежние стандартные длительности 15 и 25 секунд заменяются на 10 секунд; другие значения сохраняются. Предыдущие настройки доступны через `uci show yandex-internetometer.previous`. История измерений сохраняется, повторная установка не сбрасывает последующие изменения настроек.

## Версия 1.1.2

- Исправлена нулевая исходящая скорость: тело ответа сервера (`OK`) больше не попадает в счётчик переданных байтов.
- Ноль переданных байтов и ошибки HTTP больше не считаются успешным замером и не сохраняются в историю как завершённые.
- Upload-файл передаётся небольшими буферами без загрузки целиком в память каждого curl-процесса; отключено ожидание `100 Continue`.
- Длительность запросов ограничена оставшимся временем фазы; остановка завершает и дочерние curl-процессы.
- Добавлены регрессионные проверки переносимого shell-движка, который входит в APK/IPK.

## Версия 1.1.1

- Исправлена упаковка движка замера `transfer`: после обновления с 1.0.2 проверка скорости снова запускается.

## Версия 1.1.0

- Добавлен нативный C-модуль на libcurl. Опубликованные APK/IPK используют переносимый shell-движок; нативный модуль пока не входит в эти пакеты.
- Количество потоков и протокол (HTTP/HTTPS) подбираются автоматически по числу ядер, свободной памяти и загрузке роутера; в настройках для этого добавлено значение «Авто».
- Во время теста отслеживается загрузка CPU и доступная память; если роутеру не хватает ресурсов, результат помечается как «ограничен ресурсами устройства», а не выдаётся как есть.
- Остановка теста и сбой обрабатываются корректно: процесс больше не подвисает и не оставляет висящие curl-воркеры.
- В историю измерений добавлены поля с оценкой качества замера и пиковой загрузкой CPU/памяти.
- График истории измерений полностью переработан: плавные линии, заливка градиентом, сетка с подписями по осям (Мбит/с и даты), всплывающая подсказка при наведении.
- Исправлена нечитаемость значений в таблице истории измерений в светлой теме.
- Исправлена нечитаемость подписей в разделе «Настройки»: оформление больше не зависит от сторонней темы LuCI.

## Версия 1.0.2

- график теперь создаётся как настоящий SVG и показывает линии и точки входящей и исходящей скорости;
- кнопка «Проверить обновление» всегда видна в верхней части страницы;
- плашка обновления получила оформление для тёмной темы;

## Версия 1.0.1

Теперь результаты замеров не пропадают после обновления страницы. Приложение хранит на роутере до 200 последних измерений и показывает их в LuCI.

- Добавлен график входящей и исходящей скорости за 7, 30 или 90 дней.
- Средние скорость и пинг сравниваются с предыдущим периодом той же длины.
- Выбранный период можно выгрузить в CSV или JSON.
- В таблице отображаются десять последних измерений за выбранный период.
- Историю можно очистить из интерфейса. Публичный IP в неё не записывается.
- Файл истории доступен только `root` и ограничен 200 строками, чтобы не занимать место во флеш-памяти без контроля.
- Временные служебные файлы перенесены в защищённый каталог `/var/run`. Установщик теперь проверяет ответ серверной части и оставляет резервную копию настроек в `/etc/config`.

## Версия 1.0

Итоговый выпуск объединяет изменения, внесённые с первой версии 1.0.0.

### Замер на роутере

- Список серверов проверки и публичный IP запрашиваются по HTTPS.
- Входящий и исходящий замеры в режиме «Авто» используют проверенный HTTP CDN Яндекса. При недоступности HTTP приложение переключается на HTTPS и сообщает об этом в интерфейсе.
- Адреса CDN проходят проверку перед использованием. Исходящий замер передаёт только подготовленные нулевые данные.
- Замер использует отдельные рабочие процессы, точное монотонное время, временный файл данных в `/tmp` и корректное завершение дочерних `curl` после остановки.
- Устранены ошибки разогрева задержки, подсчёта исходящей скорости, остановки теста и проверки адресов.

### Интерфейс LuCI

- Во время теста показатели плавно обновляются. Завершённые входящая скорость, исходящая скорость и задержка сразу фиксируются на фактическом значении.
- Все числовые показатели во время замера выделяются красным и читаются в светлой и тёмной темах.
- Добавлены переключатели языка и темы, компактный блок параметров, информация о сервере, транспорте, потоках, джиттере и времени последнего запуска.
- LuCI проверяет новую версию и показывает команду обновления.

### Установка и публикация

- Универсальная команда установки определяет `apk` или `opkg`, проверяет подпись APK-репозитория либо SHA256 IPK и сохраняет UCI-настройки.
- GitHub Pages публикует подписанный APK-репозиторий, `packages.adb`, ключ и `version.json`.
- Исправлена совместимость проверки обновлений с OpenWrt jq без ONIGURUMA.

### Значения по умолчанию

| Параметр | Значение |
| --- | --- |
| Входящие и исходящие потоки | 6 / 6 |
| Транспорт | HTTP |
| Длительность входящего / исходящего теста | 15 / 25 с |
| Замеры задержки | 60, допустимый диапазон 25–120 |
| Размер данных для исходящего запроса | 8 000 000 байт |
| Исходящий тест | Включён |
| Режим отладки | Выключен |
