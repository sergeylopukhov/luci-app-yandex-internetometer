# История версий

## Версия 1.0.2

Исправления интерфейса после выпуска истории измерений:

- график теперь создаётся как настоящий SVG и показывает линии и точки входящей и исходящей скорости;
- кнопка «Проверить обновление» всегда видна в верхней части страницы;
- плашка обновления получила оформление для тёмной темы;
- рядом с командой обновления появилась кнопка копирования;
- параметр «Режим отладки» переименован в «Журнал диагностики» и получил описание.

## Версия 1.0.1

Теперь результаты замеров не пропадают после обновления страницы. Приложение хранит на роутере до 200 последних измерений и показывает их в LuCI.

- Добавлен график входящей и исходящей скорости за 7, 30 или 90 дней.
- Средние скорость и пинг сравниваются с предыдущим периодом той же длины.
- Выбранный период можно выгрузить в CSV или JSON.
- В таблице отображаются десять последних измерений за выбранный период.
- Историю можно очистить из интерфейса. Публичный IP в неё не записывается.
- Файл истории доступен только `root` и ограничен 200 строками, чтобы не занимать место во флеш-памяти без контроля.
- Временные служебные файлы перенесены в защищённый каталог `/var/run`. Установщик теперь проверяет ответ серверной части и оставляет резервную копию настроек в `/etc/config`.

## Версия 1.0

Итоговый выпуск объединяет изменения, внесённые с первой версии 1.0.0.

### Замер на роутере

- Список серверов проверки и публичный IP запрашиваются по HTTPS.
- Входящий и исходящий замеры в режиме «Авто» используют проверенный HTTP CDN Яндекса. При недоступности HTTP приложение переключается на HTTPS и сообщает об этом в интерфейсе.
- Адреса CDN проходят проверку перед использованием. Исходящий замер передаёт только подготовленные нулевые данные.
- Замер использует отдельные рабочие процессы, точное монотонное время, временный файл данных в `/tmp` и корректное завершение дочерних `curl` после остановки.
- Устранены ошибки разогрева задержки, подсчёта исходящей скорости, остановки теста и проверки адресов.

### Интерфейс LuCI

- Во время теста показатели плавно обновляются. Завершённые входящая скорость, исходящая скорость и задержка сразу фиксируются на фактическом значении.
- Все числовые показатели во время замера выделяются красным и читаются в светлой и тёмной темах.
- Добавлены переключатели языка и темы, компактный блок параметров, информация о сервере, транспорте, потоках, джиттере и времени последнего запуска.
- LuCI проверяет новую версию и показывает команду обновления.

### Установка и публикация

- Универсальная команда установки определяет `apk` или `opkg`, проверяет подпись APK-репозитория либо SHA256 IPK и сохраняет UCI-настройки.
- GitHub Pages публикует подписанный APK-репозиторий, `packages.adb`, ключ и `version.json`.
- Исправлена совместимость проверки обновлений с OpenWrt jq без ONIGURUMA.

### Значения по умолчанию

| Параметр | Значение |
| --- | --- |
| Входящие и исходящие потоки | 6 / 6 |
| Транспорт | HTTP |
| Длительность входящего / исходящего теста | 15 / 25 с |
| Замеры задержки | 60, допустимый диапазон 25–120 |
| Размер данных для исходящего запроса | 8 000 000 байт |
| Исходящий тест | Включён |
| Режим отладки | Выключен |
