luci-app-yandex-internetometer

LuCI-приложение и лёгкий CLI-backend для замера скорости интернета на OpenWrt через probe-серверы Яндекс Интернетометра.

Это неофициальная совместимая реализация. Это не ПО Яндекса и не официальный SDK. Установка проверялась только на OpenWrt с apk.
Открыть репозиторий Релиз

Установка и обновление

Одна команда ставит пакет. Повторный запуск этой же команды обновляет пакет, если вышла новая версия.

curl -fsSL https://sergeylopukhov.github.io/luci-app-yandex-internetometer/install.sh | sh

Если на роутере нет curl:

wget -O - https://sergeylopukhov.github.io/luci-app-yandex-internetometer/install.sh | sh

Что это

Пакет добавляет в OpenWrt страницу Status -> Internetometer. В русской локали пункт меню называется «Интернетометр». Во время теста интерфейс показывает текущий ping, входящую и исходящую скорость. По умолчанию используется 8 потоков.

Русский язык включён в приложении по умолчанию. Кнопка English меняет только язык этого приложения, не глобальный язык LuCI.

Что не требуется

  • VPS;
  • Ookla или speedtest.net;
  • Python, Node.js, npm или bash на роутере.

CLI

yandex-internetometer run --json
yandex-internetometer start
yandex-internetometer status
yandex-internetometer stop

Приватность

Тест обращается только к probe, upload, download и latency endpoints Яндекса, нужным для измерения. Большие файлы во flash не пишутся, временное состояние хранится в /tmp/yandex-internetometer/.
